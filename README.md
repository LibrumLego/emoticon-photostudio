# 이모티콘 사진관

카카오톡 이모티콘 PNG를 제안하기 전에 점검하는 무료 웹 도구예요. 이미지는 서버로 전송되지 않고 브라우저 안에서만 처리돼요.

**사이트:** https://librumlego.github.io/emoticon-checkroom/ · 예시 바로 보기: https://librumlego.github.io/emoticon-checkroom/?demo

## 기능
- **규격 검수:** 개수, 크기, 용량, 형식, 빈칸, 가장자리 여백, 투명 배경, 다크모드 대비를 확인해요.
- **닮은꼴·실제 크기:** 24px로 줄였을 때 가장 비슷한 짝 8개를 찾고, 실제 채팅 크기로 줄인 모습을 보여 줘요.
- **테마 갤러리:** 같은 대화를 카톡 테마 7종에 띄워서 비교해요.

## 지원 종류
| 종류 | 개수 | 크기 | 용량 |
|---|---|---|---|
| 미니 | 42 | 180×180 | 100KB |
| 멈춰있는 | 32 | 360×360 | 150KB |
| 움직이는 | 24 | 360×360 | 650KB |
| 큰 이모티콘 | 16 | 540×540 / 540×300 / 300×540 | 1MB |

카카오와 무관한 개인 도구예요. 카카오톡은 (주)카카오의 상표예요.
