# 이모티콘 사진관

카카오톡 이모티콘 PNG를 제안하기 전에 점검하는 무료 웹 도구예요. 이미지는 서버로 전송되지 않고 브라우저 안에서만 처리돼요.

**사이트:** https://librumlego.github.io/emoticon-photostudio/ · 예시 바로 보기: https://librumlego.github.io/emoticon-photostudio/?demo

## 기능
- **규격 검수:** 개수, 크기, 용량, 형식, 빈칸, 투명 배경, 움직이는 WebP의 개수와 프레임 수를 확인해요. 이것이 규격 위반이고 빨강으로 표시해요.
- **보기 점검(참고):** 다크모드에서 묻히는 그림과 가장자리 여백을 참고로 보여 줘요. 공식 규격은 아니라서 빨강으로 세지 않아요.
- **종류별 안내:** 종류를 고르면 첫 화면의 제목, 설명, 알아둘 점, 버튼 문구, 출처 안내가 그 종류에 맞게 바뀌고, 결과 화면 접수증에서도 접어서 볼 수 있어요. 예시도 고른 종류의 규격(42/32/24/16개)으로 나와요.
- **잘못 올려도 친절하게:** 파일 크기가 다른 종류의 규격과 맞으면 종류를 바꿔서 검사하고 알려 줘요. 어느 종류와도 안 맞는 단일 파일은 이전 결과를 그대로 두고 오류만 보여 줘요. 화면 어디에나 끌어다 놓을 수 있어요.
- **닮은꼴·실제 크기:** 24px로 줄였을 때 가장 비슷한 짝 8개를 찾고, 실제 채팅 크기로 줄인 모습을 보여 줘요.
- **테마 갤러리:** 같은 대화를 카톡 테마 7종에 띄워서 비교해요.

## 지원 종류
| 종류 | 개수 | 크기 | 용량 | 형식 |
|---|---|---|---|---|
| 미니 | 42 | 180×180 | 100KB | PNG |
| 멈춰있는 | 32 | 360×360 | 150KB | PNG |
| 움직이는 | 24 | 360×360 | 650KB | WebP 3개 이상(실제로 움직여야 해요) + PNG, 24프레임 이하 |
| 큰 이모티콘 | 16 | 540×540 / 540×300 / 300×540 | 1MB | WebP 3개 이상 + PNG, 24프레임 이하 |

규격은 카카오 이모티콘 스튜디오 공식 안내서 기준이에요(2026년 11월 확인). 규격은 바뀔 수 있어요. 움직이는 이모티콘의 24프레임 기준은 큰 이모티콘 페이지의 값을 같이 적용한 것이에요.

카카오와 무관한 개인 도구예요. 카카오톡은 (주)카카오의 상표예요.
