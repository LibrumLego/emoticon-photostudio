# 이모티콘 검수실

카카오톡 이모티콘을 **제안하기 전에 마지막으로 점검하는** 무료 웹 도구예요.
만든 이모티콘이 규격에 맞는지, 작게 봤을 때 구분되는지, 자주 쓰는 리액션이 빠지지 않았는지, 제출 정보가 규칙에 맞는지를 한 번에 확인할 수 있어요.

**모든 처리는 브라우저 안에서만 이루어지고, 이미지는 서버로 전송되지 않아요.**

## 기능
- **규격 검수**
  - 시트 한 장이나 낱장 파일을 불러와 개수, 크기, 용량, 형식을 체크리스트로 보여 줘요.
  - 칸마다 다음 문제를 찾아 표시해요: 가장자리 여백 부족, 배경이 칠해진 칸, 다크모드에서 묻히는 칸
- **닮은꼴·실제 크기**
  - 채팅창 크기(약 24px)로 줄였을 때 **가장 헷갈리는 표정 짝 TOP 8**을 찾아 줘요.
  - 글자 옆 크기와 단독 전송 크기에서 전체 이미지를 한눈에 보여 줘요.
- **리액션 구성**
  - 칸마다 감정이나 용도를 고르면, 필수 리액션(인사, 감사, 미안, OK 등) 중 **빠진 것**과 **너무 겹치는 감정**을 알려 줘요.
- **테마 갤러리**
  - 연인, 친구 단톡, 회사 상황의 예시 대화를 **카톡 테마 7종에 동시에** 띄워요.
  - 고른 감정에 맞춰 이모티콘이 자동으로 배치돼요.
- **제출 정보:** 작가명, 시리즈명, 이모티콘명의 글자 수와 쓸 수 있는 특수기호를 공식 안내서 기준으로 검사해요.
- **검수 리포트:** 결과를 인쇄하거나 PDF로 저장할 수 있어요.

## 지원 종류
| 종류 | 개수 | 크기 | 용량 | 기준 |
|---|---|---|---|---|
| 미니 | 42 | 180×180 | 100KB | 공식 안내서 |
| 멈춰있는 | 32 | 360×360 | 150KB | 공개 정리 자료 |
| 움직이는 | 24 | 360×360 | 650KB | 공개 정리 자료 |
| 큰 이모티콘 | 16 | 540×540 / 540×300 / 300×540 | 1MB | 공개 정리 자료 |

규격은 바뀔 수 있으니, 제안하기 전에 카카오 이모티콘 스튜디오에서 꼭 다시 확인해 주세요.

## 기술
- HTML 파일 하나로 만들었고, 외부 라이브러리를 쓰지 않아요.
- 이미지 분석은 Canvas API로 해요.
- 닮은꼴은 24px로 줄인 흑백 이미지끼리 차이를 비교해서 찾아요.

## 안내
개인이 만든 무료 도구이며 카카오와 관련이 없어요. 카카오톡은 (주)카카오의 상표예요.
