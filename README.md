# 이모티콘 사진관

카카오톡 이모티콘 PNG를 제안하기 전에 점검하는 무료 웹 도구예요. 이미지는 서버로 전송되지 않고 브라우저 안에서만 처리돼요.

**사이트:** https://librumlego.github.io/emoticon-photostudio/ · 예시 바로 보기: https://librumlego.github.io/emoticon-photostudio/?demo

## 기능
- **규격 검수:** 개수, 크기, 용량, 형식, 빈칸, 투명 배경(흰색·둥근 네모 판 포함), 움직이는 WebP의 개수와 프레임 수를 확인해요. 그림 뒤에는 투명 표시용 바둑판 무늬가 깔려요. 이것이 규격 위반이고 빨강으로 표시해요.
- **보기 점검(참고):** 다크모드에서 묻히는 그림과 가장자리 여백을 참고로 보여 줘요. 안내서의 규격이 아니라서 빨강으로 세지 않아요.
- **종류별 안내:** 종류를 고르면 첫 화면의 제목, 설명, 알아둘 점, 버튼 문구, 출처 안내가 그 종류에 맞게 바뀌고, 결과 화면 접수증에서도 접어서 볼 수 있어요. 예시도 고른 종류의 규격(42/32/24/16개)으로 나와요. 움직이는·큰 이모티콘 예시에는 HTML에 포함된 움직이는 WebP를 사용해요. 예시 이미지에 별도 네트워크 요청이 필요 없어요.
- **잘못 올려도 친절하게:** 파일 크기가 다른 종류의 규격과 맞으면 종류를 바꿔서 검사하고 알려 줘요. 단일 파일이 비어 있거나 열리지 않거나, 지원하는 형식이나 크기와 맞지 않으면 이전 결과를 그대로 두고 오류만 보여 줘요. 화면 어디에나 끌어다 놓을 수 있어요.
- **닮은꼴·실제 크기:** 24px로 줄였을 때 가장 비슷한 짝 8개를 찾고, 실제 채팅 크기로 줄인 모습을 보여 줘요.
- **테마 갤러리:** 카카오톡을 참고한 색 견본 12종에서 같은 대화를 비교해요. 내 대화방에는 직접 고른 배경 사진과 말풍선 색을 적용할 수 있어요. 사진은 현재 페이지에서만 사용해요.
- **인쇄·PDF:** 접수증과 칸 목록, 닮은꼴·실제 크기를 한 번에 출력해요. 결과가 나타나는 중에 눌러도 모든 칸이 또렷하게 찍히고, 다크모드 띠와 말풍선 색은 브라우저의 배경 인쇄 설정과 상관없이 남아요.
- **키보드:** 화면 탭(규격 검수·닮은꼴·실제 크기·테마 갤러리)은 좌우 화살표·Home·End로 옮길 수 있어요.

## 지원 종류
| 종류 | 개수 | 크기 | 용량 | 형식 |
|---|---|---|---|---|
| 미니 | 42 | 180×180 | 100KB | PNG |
| 멈춰있는 | 32 | 360×360 | 150KB | PNG |
| 움직이는 | 24 | 360×360 | 650KB | WebP 3개 이상(실제로 움직여야 해요) + PNG, 24프레임 이하 |
| 큰 이모티콘 | 16 | 540×540 / 540×300 / 300×540 | 1MB | WebP 3개 이상 + PNG, 24프레임 이하 |

규격은 카카오 이모티콘 스튜디오가 공개한 안내서를 기준으로 했어요(2026년 11월 확인). 규격은 바뀔 수 있어요. 움직이는 이모티콘의 24프레임 기준은 큰 이모티콘 페이지의 값을 같이 적용한 것이에요.

카카오와 무관한 개인 도구예요. 카카오 이모티콘 스튜디오의 공식 검수가 아니에요. 카카오톡은 (주)카카오의 상표예요.

## 개발 메모
- **보안:** CSP의 `connect-src`는 익명 통계를 위한 `https://gateway.umami.is` 연결만 허용해요. 올린 파일과 검사 결과는 기기 안에서만 처리해요.
- **글꼴:** Pretendard Variable v1.3.9의 dynamic-subset CSS를 `index.html`에 그대로 넣었어요(원본 SRI `sha384-GIdEBaqGN9mNkDkMkzMHW8EKUqtpPIe/sLj1X7DIrnc9uPtLROJgmuDlh+3rBw0j`). 글꼴 파일은 필요한 조각만 `cdn.jsdelivr.net`에서 받아요(`font-src`). 버전을 올리면 새 CSS의 SRI를 확인하고, `url(../../../`를 `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@<버전>/`로 바꿔 다시 넣어요.
- **예시 그림 글자**는 웹폰트가 받아진 뒤 그려요. 폰트가 막혀도 2초 뒤 시스템 글꼴로 그려요.
- **움직이는 예시 WebP**를 다시 만들 때는 각 예시를 8장면 PNG로 렌더링하고, 공유 128색 팔레트 + 무손실 VP8L로 묶어 `#motionAssets`에 넣어요(로컬 `qa/encode-motion.py` 방식).
- **인라인 스크립트를 고치면** `index.html`의 CSP `script-src` 해시를 다시 맞춰요. 아래 명령의 결과를 `'sha256-…'` 자리에 넣어요.
  ```bash
  node -e "const s=require('fs').readFileSync('index.html','utf8');const m=s.match(/<script>([\s\S]*?)<\/script>/);console.log('sha256-'+require('crypto').createHash('sha256').update(m[1].replace(/\r\n/g,'\n')).digest('base64'))"
  ```
  HTML은 줄바꿈을 LF로 바꿔서 읽으니, 해시도 CRLF를 LF로 바꾼 글자로 계산해야 해요(`replace(/\r\n/g,'\n')`).
- **테스트 이미지**는 `qa/`나 `_test/`에 두고 커밋하지 않아요(`.gitignore`에 있어요).

## 익명 통계 (Umami Cloud)
방문 수 같은 숫자만 익명으로 세요. 파일 이름, 이미지, 크기·용량 숫자, 검사 결과는 보내지 않아요.
- **보내는 것:** 방문 및 이벤트에는 페이지 경로(예시 링크는 `?demo` 포함), 호스트, 페이지 제목, 브라우저 언어, 화면 해상도가 포함돼요. 방문 외에 `upload`(종류, 파일 개수 구간 1·2-10·11-50·51+, 시트 여부, 종류 자동 전환 여부), `sample`(종류), `tab`(닮은꼴·실제 크기 또는 테마 갤러리, 페이지를 열 때마다 각 탭의 첫 선택 1회), `print`
- **안 보내는 경우:** 로컬이나 파일로 연 경우, 브라우저의 Do Not Track 또는 Global Privacy Control이 켜진 경우, 주소에 `?notrack`이 있는 경우
- **운영자 자기 방문 제외:** 주소 끝에 `?notrack`을 붙이면 그 주소로 연 페이지에서는 보내지 않아요.
- 보내는 주소는 `https://gateway.umami.is/api/send` 하나예요. 외부 추적 스크립트는 넣지 않아요.
- 요청에는 이 사이트의 Umami 사이트 ID(`website`, `x-umami-website-id` 헤더)와 호스트 헤더가 함께 가고, 쿠키는 보내지 않아요(`credentials: 'omit'`). 종류와 탭 값은 영어 코드(`mini`·`still`·`anim`·`large`, `look`·`themes`)로 보내요.
